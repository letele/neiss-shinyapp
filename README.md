# 🚀 NEISS Decision Intelligence Shiny App

[![R](https://img.shields.io/badge/R-4.3.1-blue.svg)](https://www.r-project.org/)
[![Shiny](https://img.shields.io/badge/Shiny-App-orange.svg)](https://shiny.rstudio.com/)
[![Deploy to shinyapps.io](https://img.shields.io/badge/deploy-shinyapps.io-blue?logo=r)](#)

Interactive **Shiny** dashboard for exploring the **NEISS injury dataset**.  
Explore injury trends across demographics, locations, and age groups.

## 🎯 Features

- **Overview**: High-level statistics and insights.  
- **Cross Analysis**: Compare variables like race, sex, and body part.  
- **Age Groups**: Analyze injuries by age categories.  
- **Location Heatmap**: Visualize injury hotspots with interactive maps.  

## 🎨 Technologies Used

- **R Shiny** – interactive web app  
- **dplyr / tidyr** – data manipulation  
- **ggplot2 / svglite** – data visualizations
